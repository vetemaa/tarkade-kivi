# Tarkade kivi ja kannabinoidid

Markus Vetemaa e-raamatu allalaadimisleht.

## Otsingunähtavus

Leht sisaldab otsingumootoritele mõeldud pealkirja ja kirjeldust, Book JSON-LD
struktuurandmeid, Open Graphi jagamispilti, `robots.txt`-i ning `sitemap.xml`-i.

Pärast avaldamist lisa `https://vetemaa.github.io/tarkade-kivi/` Google Search
Console’i URL-i kontrolli kaudu ja esita seal sitemap:

`https://vetemaa.github.io/tarkade-kivi/sitemap.xml`

Kui leht kolitakse kohandatud domeenile, uuenda korraga kanoniline URL,
Open Graphi URL-id, JSON-LD URL-id, `robots.txt` ja `sitemap.xml`.
